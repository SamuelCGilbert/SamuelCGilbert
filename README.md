# Hi, I'm Sam 👋

I like building small apps, automations and fixes for the things I use every day.

## Projects

- **[Getogether](https://github.com/SamuelCGilbert/getogether)**: a shared
  calendar for a group of friends: plans, RSVPs, date polls, bring lists, rides
  and costs. Live at [getogether.app](https://getogether.app).
- **[Trawlr](https://github.com/SamuelCGilbert/trawlr)**: instant file-name
  search for Linux, Windows and macOS with an always-current index, in the
  spirit of Everything. [trawlr.io](https://trawlr.io)
- **[Quipkey](https://github.com/SamuelCGilbert/quipkey)**: press a hotkey,
  speak, and the text is typed into any app. Local, private speech recognition
  for Windows and Linux. [Download](https://github.com/SamuelCGilbert/quipkey/releases/latest)
- **[EasyInstall](https://github.com/SamuelCGilbert/easyinstall)**: pick Windows
  apps, download one file, and install or update them all silently. Live at
  [easyinstall.dev](https://easyinstall.dev).
- **[MouseProbe](https://github.com/SamuelCGilbert/mouseprobe)**: finds what
  makes your mouse stutter on Windows: slow mouse hooks in other programs, or
  wireless/USB dropouts. [Download](https://github.com/SamuelCGilbert/mouseprobe/releases/latest)

## Linux apps on Wayland

Moving from X11 to Wayland broke a lot of the desktop tools I rely on. These
forks and small tools get them working again, mostly on KDE Plasma 6.

| App | What it fixes |
|---|---|
| [Flameshot](https://github.com/SamuelCGilbert/flameshot) | Pinned screenshots open where you captured them and stay on top; faster capture on KDE. [Download the AppImage](https://github.com/SamuelCGilbert/flameshot/releases/latest) |
| [Touchégg](https://github.com/SamuelCGilbert/touchegg) | Touchpad gestures work in a KDE Plasma Wayland session. [.deb and .rpm packages](https://github.com/SamuelCGilbert/touchegg/releases/latest) |
| [kwin-touchpad-gesture-blocker](https://github.com/SamuelCGilbert/kwin-touchpad-gesture-blocker) | Stops KDE's own 3+ finger gestures so Touchégg's run alone |
| [AutoKey for Wayland](https://github.com/SamuelCGilbert/autokey-wayland) | Hotkeys and text expansion on KDE Plasma without root or uinput. [.deb and .rpm packages](https://github.com/SamuelCGilbert/autokey-wayland/releases/latest) |
| [autokey-kwin-bridge](https://github.com/SamuelCGilbert/autokey-kwin-bridge) | The KWin plugin AutoKey uses for key events and hotkeys |
| [kwin-input](https://github.com/SamuelCGilbert/kwin-input) | Send keys and clicks and take screenshots on KDE Plasma, without root. [.deb and .rpm packages](https://github.com/SamuelCGilbert/kwin-input/releases/latest) |
| [CopyQ](https://github.com/SamuelCGilbert/CopyQ) | The tray menu closes when you click away. [Download the AppImage](https://github.com/SamuelCGilbert/CopyQ/releases/latest) |
| [OculiX](https://github.com/SamuelCGilbert/Oculix) | Screen capture, input and the recorder work with Wayland windows on KDE |
| [kwin-wayland-window-fixes](https://github.com/SamuelCGilbert/kwin-wayland-window-fixes) | "Bring window to current desktop" moves the window instead of copying it |
| [easystroke-to-inputactions](https://github.com/SamuelCGilbert/easystroke-to-inputactions) | Converts easystroke mouse gestures for Input Actions |
| [Input Actions Editor](https://github.com/SamuelCGilbert/InputActionsEditor) | Adds a page for turning mouse gestures off in chosen apps. [Downloads](https://github.com/SamuelCGilbert/InputActionsEditor/releases/latest) |
